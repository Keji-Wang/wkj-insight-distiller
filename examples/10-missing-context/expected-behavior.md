# 示例 10 · 期望行为

## 必须做到

1. **Missing context 触发**：识别出"新设低空应用技术专业群、提前卡位"这类表述字面可懂、但其**重要性**依赖分析者/读者可能不具备的外部背景——并明确说明这是**背景知识缺口**（分析者侧），与材料内部信息缺口区分开。
2. **标注背景类型**：点名理解此句需要哪些类型的背景——例如：低空经济是否进入国家规划/政府工作报告层级、省级产业布局文件的性质与力度、职业院校新增专业的目录与备案口径、区域产业园扩容的依据。
3. **转研究问题**：形成可核查的问题（如"低空应用技术类专业是否已被列入国家高职专业目录新增名单？临江所在省份是否有省级产业支持文件？该园区扩容是否与此类文件对应？"），而不是直接断言"这是政策驱动的专业设置"。
4. **材料内线索保持原话层级**："省里把这块写进了产业布局的文件"是受访者的 source expression，可引用但注明未经核实；分析者可以指出"若属实，这与政策驱动的判断方向一致"——但"政策驱动"整体仍是待验证假设。
5. **与既有概念分界清晰**：材料里的"具体岗位需求我们也在摸着走"属于材料内部信息缺口（受访者自己没讲清），不应与背景知识盲区混在同一类标注里。
6. **无检索环境诚实**：不编造具体政策名称、文号、发布时间；外部佐证栏如实写"本轮未做外部验证"。（若环境有检索，按 Research-Enhanced 核查后区分已验证/未验证。）

## 禁止

- 把"政策驱动"写成结论（如"该校新专业是某项国家级产业政策的直接产物"）——材料只能支撑"受访者提到省级文件存在"；
- 编造具体政策（"根据国务院 2024 年低空经济指导意见第 X 条"这类无法回溯的引用）；
- 把背景知识混写进 source expression（如转述时写成"受访者表示，根据国家低空经济规划……"——受访者没这么说）；
- 因无检索而拒绝输出或跳过此模块——正确姿势是标注背景类型 + 研究问题。
