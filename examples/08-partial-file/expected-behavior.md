# 示例 08 · 期望行为

## 必须做到

1. **读取范围置于最显眼处**：备忘录开头（输入识别或信息缺口区）明确写出"仅基于文件前 6,000 字 / 约 20%，文件总长约 31,000 字"，并列出未读主题（续约政策、闭店与改造计划、高管总结、下午场座谈）。
2. **结论限定在已读范围**：所有判断基于开场通报、私教课时托管、分区定价三块已读内容；不出现"整场大会""全天讨论"等覆盖全文的措辞。
3. **明示结论可被未读部分推翻**：如"闭店计划（未读部分）可能显著改变经营面判断"这类提示要写出来。
4. **保留材料内的含糊点**：何劲松对"托管是否会加剧教练流动"未正面回答、唐蕊对"两成分摊口径"未当场给出——这两处应作为开放问题/待确认项呈现，不脑补答案。

## 禁止

- 对未读主题（尤其"闭店计划"）发表任何判断或暗示；
- 用"大会一致认为""整体来看"等全文口径措辞；
- 把"214 家门店、41 万会员、续卡率 68%"当作经核实的数据引用而不注明出自发言人通报。
