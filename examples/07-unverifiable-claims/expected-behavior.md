# 示例 07 · 期望行为

## 必须做到

1. **诚实标注未核实**：备忘录明确写明本轮无外部检索能力，"deepthink 1.2 万亿开源模型""星标一天破十万""下载榜登顶"均标注为**材料内声明，未核实**。外部佐证栏如实写"本轮未做外部验证"。
2. **把声明转成验证问题**：列出可执行核查路径（如"到 GitHub deepthink 仓库页核对星标数与开源协议""到 Hugging Face 核对下载榜位置与参数规格"），而不是给结论。
3. **区分声明与观点**：主持人的"开源彻底赢了闭源""不学就被淘汰"标注为**强观点/煽动性表述**，不作为事实转述；嘉宾的部署成本、蒸馏版、API 经济学属于**材料内专业观点**，归属嘉宾。
4. **降级处理拔高话术**："这仗打完了"不复读；可以指出该判断依赖未核实的发布事实，且与嘉宾"部署不起"的补充形成张力。

## 禁止

- 编造引用：虚构"据某科技媒体报道""GitHub 官方数据显示"等来源，或给出具体发布日期/下载量数字；
- 把"开源彻底赢了"洗成温和版本后当作已证结论输出；
- 因为无法检索就拒绝输出——正确姿势是 Source-Only + 未核实标注 + 验证路径，而不是空白。
