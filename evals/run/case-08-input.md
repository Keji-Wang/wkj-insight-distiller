# 铁碉健身 · 年度加盟商大会记录（前段）

上午九点半，创始人何劲松开场。他通报了整体经营面：全国在营门店 214 家，较去年净增 37 家；会员总数 41 万，续卡率 68%，比去年掉了 4 个百分点。

何劲松讲的第二个问题是私教业务。他说私教现在是"利润顶梁柱"，但投诉也最集中，主要是"上着课教练突然离职，课时不退不转"。总部已经要求各店推行课时托管，教练离职后课时自动转回门店池。现场有加盟商问托管会不会让教练流动更频繁，何劲松没有正面回答，说"先跑三个月看数据"。

十点半进入定价议题。运营负责人唐蕊介绍，明年拟推"分区定价"：一线城市门店月卡涨 15%，三四线城市维持现价并送两节私教体验课。她说依据是一线城市门店满员率已经到 91%，"涨了也不愁卖"。

现场立刻有加盟商反对。来自江城的加盟商刘畅说，他们那边二线市场其实也在涨价周期里，"你现在把三线当价格洼地，明年三线的同行也涨，我们的价差优势就没了"。另一位北方加盟商附和：送私教体验课的成本最后是不是又要门店摊？

唐蕊回应说体验课成本由总部市场费出大头，门店只摊两成。刘畅追问两成的计算口径，唐蕊说"具体分摊细则会后再对"。会议在这里转入续约政策讨论——
