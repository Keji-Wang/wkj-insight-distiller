【虚构演示】以下是一段虚构科技播客《奇点晚班》的转录片段。当前会话没有联网检索工具。

---

**主持人**：上周最大的事，deepthink 发布了他们那颗 1.2 万亿参数的开源模型，直接免费商用。GitHub 星标一天破十万，Hugging Face 下载榜直接登顶。我说这话可能有点武断，但这基本上标志着开源彻底赢了闭源，这仗打完了。

**嘉宾**：登顶是事实，我当天就下了。不过"彻底赢了"我不同意，推理成本摆在那儿，1.2 万亿的模型，一般公司根本部署不起，得配八卡以上的机器。

**主持人**：那你们小公司怎么办？

**嘉宾**：等蒸馏版呗，或者干脆调用 API。我们算过，自建不如调 API 划算，调用量上不去的时候尤其明显。

**主持人**：所以普通人现在该做的就是赶紧学起来，现在不学就被淘汰了，这话我放这儿。
