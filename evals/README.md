# Evals

8 个用例的输入在 `run/`（纯材料，不含期望行为说明，可直接用于盲跑）。期望行为与逐条判定标准在 `../examples/<case>/expected-behavior.md`。

## 手动复跑方法

1. 把本仓库放入你的 agent 的 skills 目录（或把 `SKILL.md` 与 `references/` 粘贴进任何支持"读取本地文件"的会话）。
2. 让 agent 读取 `run/case-0N-input.md` 并按 skill 处理。保持一次交互（one-shot），不额外提示。
3. 对照对应用例的 `expected-behavior.md` 逐条核对。

## 判定口径

- **通过**：该用例"必须做到"全部满足，"禁止"零命中。
- **部分通过**：核心门槛满足（如 03 的确认块形态），但存在轻微越界（如夹带了少量分析）。
- **失败**：命中任一"禁止"项，或未执行"必须做到"的核心项。

`docs/validation.md` 记录了每次正式试跑的日期、执行模型与逐例结果。复跑结果不同是正常现象——这个 skill 的行为依赖具体模型，验证记录只对当次运行负责。
