# Contributing

Issues and pull requests are welcome. A few rules keep this skill honest:

1. **Fictional material only.** Examples and tests must use invented people, companies, and events. Real interviews, meeting notes, or client material must never enter this repository.
2. **Keep the source-grounded discipline.** Do not add rules, examples, or wording that promise "automatic truth extraction" or "zero hallucination". The skill's value is calibrated judgment, not magic.
3. **Run the evals before changing core rules.** If your PR changes `SKILL.md` or `references/`, state in the description whether you re-ran the cases in `evals/` and what changed.
4. **Credit ideas, don't absorb text.** If a contribution borrows a concept from another skill or article, add it to `SOURCES.md`. Do not paste third-party text.
5. **License stays MIT** for this repository's own content.
